# Day 1 · 日常生活漢字（20 張）

JLPT N3–N2 入門日常漢字，適合香港學習者。

## 內容
- `cards.json` — 20 張卡資料（漢字、音／訓、粵語意思、例句、圖片路徑）
- `images/` — 20 張可愛 flat vector 插圖（無文字）
- `index.html` — 跳轉去上層主應用

## 漢字一覽
開・閉・働・休・急・遅・通・駅・乗・降・買・売・払・貸・借・薬・病・館・約・会

## 用法
請開啟上層 **`../index.html`**（主應用），內有：
1. **開始翻卡** — 正面：圖 + 漢字；背面：音読み／訓読み、粵語意思、例句、「讀一次」TTS
2. **今日小測** — 約 10 題（睇圖揀漢字、揀讀音、例句意思）

離線用：用瀏覽器直接開 `../index.html`（若 fetch 被擋，可用 `python3 -m http.server` 喺 `flashcards/` 目錄跑）。
